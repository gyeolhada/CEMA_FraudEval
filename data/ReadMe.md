# trainResult.csv

 (Fraud-dialogue dataset provided by the instructor)

Contains the processed training data with model predictions/confidences.  

Used for:
- Building the auxiliary set (`01_build_auxiliary.py`)
- Training substitute models and preparing the victim model (`02_train_substitute.py`, `04_select_and_evaluate.py`)

---

# testResult.csv

(Fraud-dialogue dataset provided by the instructor)  

Used only for evaluation.  

Also serves as the source for:
- Generating adversarial candidates in `03_generate_candidates.py`
- Evaluating victim model performance on original vs. adversarial texts in `04_select_and_evaluate.py`

---

# test_candidates.csv

Generated by 03_generate_candidates.py.

Contains multiple adversarial candidate sentences for every test sample.

These include:
- synonym-based replacements
- paraphrase-based rewrites
- logic-insertion variations
(Back-translation disabled in this project version.)

This file serves as the input to the adversarial selection module (04_select_and_evaluate.py).

---

# test_with_cema_selected.csv

Generated by 04_select_and_evaluate.py.

Contains the final adversarial samples selected by the CEMA strategy, along with:
- victim model predictions
- substitute model ensemble votes
- evaluation metrics used for computing ASR (Attack Success Rate)

This file represents the final adversarial evaluation results.

---

# auxiliary/

Generated by `01_build_auxiliary.py`.  

Contains cleaned pseudo-unlabeled samples (e.g., `aux_texts.csv`) used for training the substitute models.
